# AI-Driven Formative Assessments (CBC Grades 4–6)

An adaptive quiz system for Kenyan CBC Grades 4–6 that pairs a FastAPI backend (auth, OTP/Google login, quiz persistence, adaptive routing) with a Streamlit frontend for parents and learners. Quizzes are generated by an external finetuned LLM service (e.g., LLaMA/Mistral) and aligned to Blooms taxonomy.

## Project Overview

This system delivers Bloom-aligned formative assessments per learner profile:
- Adaptive Bloom levels: Remember  Create
- Subject/topic targeting with grade normalization (Grade 4Grade 6)
- Weak-spot reinforcement and stem avoidance across recent attempts
- JWT-secured parent flows: email+OTP and Google OAuth

**Models/Engines:**
- External quiz engine (finetuned LLaMA/Mistral) reachable via `QUIZ_ENGINE_URL`
- SQLite-backed attempt history to drive adaptation logic

**Performance:**
- UI/UX focused prototype; model quality depends on the external engine and fine-tuning data (see `notebooks/mistral.ipynb`).

## Requirements

## Local Setup

### 1. Clone the repository
```bash
git clone <repo-url>
cd Enhancing-STEM-Education-in-CBC-through-AI-Driven-Formative-Assessments-A-Case-of-Grades-4-to-6
```

### 2. Create and activate virtual environment

**Create virtual environment (all OS):**
```bash
python -m venv .venv
```

**Check your Python version:**
```bash
python --version
```

**Activate virtual environment:**

macOS/Linux:
```bash
source .venv/bin/activate
```

Windows (Command Prompt):
```cmd
.venv\Scripts\activate.bat
```

Windows (PowerShell):
```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies
```bash
pip install --upgrade pip setuptools wheel
pip install -r backend/requirements.txt
```

### 4. Configure environment
Copy `.env` (do not commit secrets) and set:
- `SECRET_KEY`  JWT signing secret
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`  for OTP email
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`  Google OAuth
- `BACKEND_URL`, `FRONTEND_URL`  public/base URLs
- `QUIZ_ENGINE_URL`  external quiz generator endpoint
- `QUIZ_API_KEY`  optional, forwarded as `X-API-Key`

### 5. Run the backend (FastAPI)
```bash
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

### 6. Run the frontend (Streamlit)
In a second shell (same venv):
```bash
streamlit run frontend/app.py --server.port 8501
```

### 7. Open the app
Visit `http://localhost:8501`. Google OAuth redirects back through the backend to the frontend.

## API Endpoints

- `POST /auth/register`  Create parent; sends welcome email.
- `POST /auth/login`  Verify password, send OTP.
- `POST /auth/verify-otp`  Exchange OTP for JWT.
- `POST /auth/profiles`  Create child profile (JWT required).
- `GET /auth/profiles`  List child profiles (JWT required).
- `GET /auth/google/redirect`  Start Google OAuth.
- `GET /auth/google/callback`  Exchange code, provision parent if new, return JWT to frontend.
- `POST /quiz/generate`  Build adaptive context and request quiz from quiz engine.
- `POST /quiz/submit`  Persist attempt + per-question details.
- `GET /quiz/recent`  Recent attempts by profile.
- `GET /quiz/attempt/{id}`  Attempt with question-level details.

## Troubleshooting

**Python version error?**
```bash
python --version  # Expect 3.10+
```

**Virtual environment not active?**
macOS/Linux:
```bash
source .venv/bin/activate
```
Windows (Command Prompt):
```cmd
.venv\Scripts\activate.bat
```
Windows (PowerShell):
```powershell
.venv\Scripts\Activate.ps1
```

**Quiz engine 502/timeout?**
- Ensure `QUIZ_ENGINE_URL` is reachable and you forwarded the correct port/ngrok URL.
- Set `QUIZ_API_KEY` if your engine enforces it.

**OAuth redirect issues?**
- Align `GOOGLE_REDIRECT_URI`, `BACKEND_URL`, and `FRONTEND_URL` (including ports) in Google Console and `.env`.

**Port already in use?**
```bash
uvicorn backend.main:app --reload --port 8001
streamlit run frontend/app.py --server.port 8502
```

**Out of memory on engine?**
- Reduce model context/window or batch size in your hosted engine; backend itself is lightweight.
